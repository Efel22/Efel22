# 💫 About Me:
I’m a Computer Science student and game developer with a strong interest in gameplay programming, procedural generation, and systems design. I enjoy building games and tools in Python (Pygame CE), Unity, Unreal Engine, and Minecraft data packs, blending code, design, and pixel art to create immersive gameplay experiences. I’m especially passionate about RPG systems, AI behaviors, world generation, and combat mechanics, and I love experimenting with ideas that mix technical depth with creative expression.
